Creating an Array

To create an array in C++, you specify the type of elements the array will hold and the number of elements in the array. 

#include <iostream>

int main() {
// Creating an array of integers with 5 elements
int numbers[5];

// Assigning values to array elements
numbers[0] = 10;
numbers[1] = 20;
numbers[2] = 30;
numbers[3] = 40;
numbers[4] = 50;

return 0;
}
  • In this example, we declare an array of integers named numbers with 5 elements.
  • Each element in the array can be accessed using an index, starting from 0 to 4 (total of 5 elements).
  • We assign values to each element of the array using their respective indices.

You can also create an array and initialize its elements at the same time using curly braces { }. This method is more convenient and often preferred over assigning values to individual array elements one by one. 

#include <iostream>

int main() {
// Creating an array of integers with 5 elements and initializing them
int numbers[5] = {10, 20, 30, 40, 50};

return 0;
}
  • We declare an array of integers named numbers with 5 elements.
  • We initialize the array with values {10, 20, 30, 40, 50} within curly braces { }.
  • Each value inside the braces corresponds to an element in the array, in the order they appear.

This approach is simpler and more concise, especially when you know the initial values of the array elements at the time of declaration.

Accessing Array Elements

You can access array elements by specifying the index of the element within square brackets [ ]. 

#include <iostream>

int main() {
int numbers[5] = {10, 20, 30, 40, 50};

// Accessing array elements
std::cout << "Element at index 2: " << numbers[2] << std::endl;

return 0;
}
  • In this example, we declare an array of integers named numbers with 5 elements.
  • We access the element at index 2 (which is the third element in the array) using numbers[2].
  • The output will be the value stored at index 2, which is 30. 
Output:

30

Changing Array Elements

You can change the value of an array element by assigning a new value to it using its index. 

#include <iostream>

int main() {
int numbers[5] = {10, 20, 30, 40, 50};
std::cout << "Before changing the array element value: " << numbers[3] << std::endl;
// Changing array elements
numbers[3] = 45;
std::cout << "After changing the array element value: " << numbers[3] << std::endl;
return 0;
}
  • In this example, we change the value of the element at index 3 (which is the fourth element in the array) to 45.
  • After this change, the value of numbers[3] will be 45. 
Output:

Before changing the array element value: 40
After changing the array element value: 45

NOTE: Remember that array indices in C++ start from 0. Always be cautious with array bounds to avoid accessing elements outside the array, which can lead to unexpected behavior or errors.
