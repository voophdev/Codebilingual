while loop

A while loop is a control flow statement in C++ that executes a block of code repeatedly as long as a specified condition is true. Unlike the for loop, the while loop does not have initialization or increment/decrement expressions within the loop syntax. Instead, it relies solely on a condition to determine when to terminate.

The syntax of a for loop in C++ is as follows: 

while (condition) {
// code to be executed
// This block of code will be executed repeatedly
// as long as the condition remains true
}

Here's an explanation of each part of the while loop:

  1. Condition

    The while loop starts by evaluating this condition. If the condition is true, the code inside the loop is executed. If the condition is false, the loop terminates, and the program continues with the code after the loop.

  2. Loop Body

    This is the block of code that gets executed repeatedly as long as the condition remains true.

Here's a simple example of a while loop in C++: 

#include <iostream>

int main() {
int i = 0;
while (i < 5) {
  std::cout << "Iteration " << i + 1 << std::endl;
  ++i;
}

return 0;
}

Let's break it down:

  1. int i = 0; initializes the loop control variable i to 0 before the loop begins
  2. int < 5; is the condition. The loop will continue as long as i is less than 5.
  3. i++ increments i after each iteration.
  4. std::count << "Iteration " << i + 1 << std:: endl; is the loop body. It prints the current iteration number to the console. 
Output:

Iteration 1
Iteration 2
Iteration 3
Iteration 4
Iteration 5

The loop runs five times, printing the current iteration number each time, from 1 to 5.
