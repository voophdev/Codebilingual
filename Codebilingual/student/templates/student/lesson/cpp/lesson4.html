Arithmetic Operators

Arithmetic operators are used to perform mathematical operations.

#include <iostream>
using namespace std;

int main() {
  int a = 10, b = 5;
  int sum = a + b;  // '+' = Addition
  int difference = a - b;  // '-' = Subtraction
  int product = a * b;  // '*' = Multiplication
  int quotient = a / b;  // '/' = Division
  int remainder = a % b;  // '%' = Modulus (remainder)

  cout << "Sum: " << sum << endl;
  cout << "Difference: " << difference << endl;
  cout << "Product: " << product << endl;
  cout << "Quotient: " << quotient << endl;
  cout << "Remainder: " << remainder << endl;

  return 0;
}

This C++ code performs basic arithmetic operations on two integer variables a and b, and then prints out the results. Here's a simplified explanation:

  • int a = 10, b = 5;: Initializes two integer variables a and b with values 10 and 5 respectively.
  • int sum = a + b;: Adds a and b and stores the result in sum variable.
  • int difference = a - b;: Subtracts b from a and stores the result in difference variable.
  • int product = a * b;: Multiplies a and b and stores the result in product variable.
  • int quotient = a / b;: Divides a by b and stores the integer quotient in quotient variable.
  • int remainder = a % b;: Calculates the remainder when a is divided by b and stores it in remainder variable.

After performing these operations, the code prints out the values of sum, difference, product, quotient, and remainder using cout.

Output:

Sum: 15
Difference: 5
Product: 50
Quotient: 2
Remainder: 0

Relational Operators

Relational operators are fundamental elements in programming langs like C++ that enable the comparison of two values to establish their relationship. These operators provide a means to evaluate expressions and make logical decisions based on the relative magnitudes or equality of the values involved. They help in understanding how values relate to each other in terms of their numerical or textual representation.

  1. Equal to ('=='): Checks if two values are equal.

    int a = 5, b = 5;

  if (a == b) {
      cout << "a is equal to b" << endl;
  }

  //Output: a is equal to b

  2. Not equal to ('!='): Checks if two values are not equal.

    int x = 10, y = 20;

  if (x != y) {
      cout << "x is not equal to y" << endl;
  }

  //Output: x is not equal to y

  3. Greater than to ('>'): hecks if the left operand is greater than the right operand.

    float p = 3.14, q = 2.71;

  if (p > q) {
      cout << "p is greater than q" << endl;
  }

  //Output: p is greater than q

  4. Less than ('<'): Checks if the left operand is less than the right operand.

    int m = 15, n = 20;

  if (m < n) {
      cout << "m is less than n" << endl;
  }

  //Output: m is less than n

  5. Greater than or equal to ('>='): Checks if the left operand is greater than or equal to the right operand.

    int x = 25, y = 20;

  if (x >= y) {
      cout << "x is greater than or equal to y" << endl;
  }

  //Output: x is greater than or equal to y

  6. Less than or equal to ('<='): Checks if two values are equal.

    int a = 10, b = 15;

  if (a <= b) {
      cout << "a is less than or equal to b" << endl;
  }

  //Output: a is less than or equal to b

Logical Operators

Logical operators in C++ are used to perform logical operations on boolean expressions. These operators help in combining multiple conditions or boolean values to create more complex conditions.

Operator Description Example Result
&& Logical AND x > 0 && x < 10 True if both conditions are true
|| Logical OR x == 0 || x == 10 True if at least one condition is true
! Logical NOT !flag True if flag is false, false if flag is true

  1. Logical AND ('&&')

    The logical AND operator returns true if both operands are true, otherwise, it returns false.

    int x = 5, y = 10;
  if (x > 0 && y > 0) {
    cout << "Both x and y are positive." << endl;
  }
    Output:
  Both x and y are positive.

  2. Logical OR ('||')

    The logical OR operator returns true if at least one of the operands is true, otherwise, it returns false.

    int x = 5, y = -5;
  if (x > 0 || y > 0) {
      cout << "At least one of x and y is positive." << endl;
  }
    Output:
  At least one of x and y is positive.

  3. Logical NOT ('!')

    The logical NOT operator reverses the logical state of its operand. If the operand is true, it returns false, and if the operand is false, it returns true.

    #include <iostream>
  using namespace std;

  int main() {
      // Declare a boolean variable
      bool sunny = true;
      
      // Check if it's sunny or not
      if (sunny) {
          cout << "It's sunny outside!" << endl;
      } else {
          cout << "It's not sunny outside." << endl;
      }
      
      return 0;
  }
    Output:

  At least one of x and y is positive.

NOTE: Logical operators play a key role in programming because they enable a system or program to take specific decisions depending on the specific underlying conditions.

Bitwise Operators

Bitwise operators in C++ are used to perform operations at the bit level. These operators manipulate individual bits of integer operands.

There are several bitwise operators in C++, including:

  1. Bitwise AND &

    Performs a bitwise AND operation on each pair of corresponding bits. The result is 1 if both bits are 1, otherwise 0.

  2. Bitwise OR |

    Performs a bitwise OR operation on each pair of corresponding bits. The result is 1 if at least one of the bits is 1, otherwise 0.

  3. Bitwise XOR ^

    Performs a bitwise exclusive OR operation on each pair of corresponding bits. The result is 1 if the bits are different, otherwise 0.

  4. Bitwise NOT ~

    Performs a bitwise NOT operation on each bit, inverting its value. 1 becomes 0, and 0 becomes 1.

  5. Left Shift <<

    Shifts the bits of the left operand to the left by the number of positions specified by the right operand.

  6. Right Shift >>

    Shifts the bits of the left operand to the right by the number of positions specified by the right operand.

Here's a brief example demonstrating the usage of bitwise operators:

#include <iostream>
using namespace std;

int main() {
  int a = 5; // Binary: 0101
  int b = 3; // Binary: 0011

  // Bitwise AND
  int result_and = a & b; // Result: 0001 (1 in decimal)

  // Bitwise OR
  int result_or = a | b; // Result: 0111 (7 in decimal)

  // Bitwise XOR
  int result_xor = a ^ b; // Result: 0110 (6 in decimal)

  // Bitwise NOT
  int result_not = ~a; // Result: 1111 1111 1111 1111 1111 1111 1111 1010 (-6 in decimal, assuming 32-bit integers)

  cout << "Bitwise AND: " << result_and << endl;
  cout << "Bitwise OR: " << result_or << endl;
  cout << "Bitwise XOR: " << result_xor << endl;
  cout << "Bitwise NOT: " << result_not << endl;

  return 0;
}
OUTPUT:

Bitwise AND: 1
Bitwise OR: 7
Bitwise XOR: 6
Bitwise NOT: -6

This is a basic overview of bitwise operators in C++. They are often used in low-level programming, such as device driver development, embedded systems, and cryptography.
