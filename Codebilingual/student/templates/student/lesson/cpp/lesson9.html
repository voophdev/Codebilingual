#include <iostream>
  
int main() {
    int day = 3;

    switch (day) {
        case 1:
            std::cout << "Monday" << std::endl;
            break;
        case 2:
            std::cout << "Tuesday" << std::endl;
            break;
        case 3:
            std::cout << "Wednesday" << std::endl;
            break;
        case 4:
            std::cout << "Thursday" << std::endl;
            break;
        case 5:
            std::cout << "Friday" << std::endl;
            break;
        default:
            std::cout << "Weekend" << std::endl;
            break;
    }

    return 0;
  }

In this example, the variable day is evaluated in the switch statement. Depending on the value of day, the corresponding case label is executed. Here, day is assigned the value 3, so the code block associated with case 3 is executed, printing "Wednesday" to the console.

Output: 
  
  Wednesday

The break keyword

The break keyword is used to exit the switch block after executing the code associated with a specific case. When a break statement is encountered, the program exits the switch statement entirely, preventing execution from falling through to subsequent cases.

The default keyword

The default keyword is used to define a block of code that executes when none of the case labels match the value of the expression being evaluated. It serves as a catch-all case for values that don't have specific case labels defined.

Let's explore the use of break and default within a switch statement with an example:

#include <iostream>
  
int main() {
    int choice = 3;

    switch (choice) {
        case 1:
            std::cout << "You chose option 1" << std::endl;
            break; // Exit the switch block after executing case 1
        case 2:
            std::cout << "You chose option 2" << std::endl;
            break; // Exit the switch block after executing case 2
        case 3:
            std::cout << "You chose option 3" << std::endl;
            break; // Exit the switch block after executing case 3
        default:
            std::cout << "Invalid choice. Please select a valid option." << std::endl;
            break; // Exit the switch block if no other case matches
    }

    return 0;
}
  • In this example, the variable choice is evaluated in the switch statement.
  • Each case represents a different option that the user might choose.
  • The break statement is used after each case block to exit the switch statement once the corresponding case is executed. Without break, the program would continue executing the code for subsequent cases.
  • The default case is executed if the value of choice does not match any of the defined cases (1, 2, or 3). It serves as a catch-all for invalid choices. 
Output (when choice = 3):

You chose option 3

In this scenario, the value of choice is 3, so the case associated with 3 is executed, printing "You chose option 3" to the console. After executing the code block for case 3, the break statement causes the program to exit the switch block, preventing the execution of subsequent cases. Therefore, the program does not execute the default case in this scenario.

NOTE:Ensure each case in the switch statement ends with a break statement to avoid unintended fall-through behavior.
