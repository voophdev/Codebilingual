Integer

An integer is a data type used to represent whole numbers without fractional parts. Integers can be both positive and negative.

#include <iostream>

int main() {
    // Declare an integer variable named 'age' and assign it the value 25
    int age = 25;

    // Print the value of 'age' to the console
    std::cout << "Age: " << age << std::endl;

    return 0;
}
Output: 

25

Float

Floating-point numbers are those that have a fractional part, allowing for a wider range of values than integers. Floats are typically used when dealing with real numbers that require decimal precision.

#include <iostream>

int main() {
    // Declare a float variable named 'distance' and initialize it with a value
    float distance = 10.5;

    // Print out the value of the 'distance' variable
    std::cout << "Distance: " << distance << std::endl;

    return 0;
}
Output:

Distance: 10.5

Double

A double is a fundamental data type used to represent floating-point numbers with double precision. It offers higher precision compared to float and occupies more memory space.

#include <iostream>

int main() {
    double pi = 3.14159265358979323846;
    std::cout << "Value of pi: " << pi << std::endl;
    return 0;
}
Output:

Value of pi: 3.14159265358979323846

Char

A char is a fundamental data type used to represent a single character.

#include <iostream>

int main() {
    char grade = 'A'; // Assigning the character 'A' to the variable 'grade'

    std::cout << "The grade is: " << grade << std::endl;

    return 0;
}
Output:

The grade is: A

Bool

A bool is a fundamental data type used to represent boolean values, which can either be true or false. Commonly used in decision-making statements.

#include <iostream>

int main() {
    bool isRaining = true;
    
    if (isRaining) {
        std::cout << "Take an umbrella!" << std::endl;
    } else {
        std::cout << "No need for an umbrella today." << std::endl;
    }
    
    return 0;
}
Output:

Take an umbrella!
  • The variable isRaining is initialized with the value true.
  • The program checks the condition (isRaining), which evaluates to true, so the code inside the if statement block is executed, printing "Take an umbrella!".

String

A string is a sequence of characters stored as a single data entity. C++ strings are versatile data types used to handle sequences of characters that can efficiently manage text-based data in a program.

#include <iostream>
#include <string>

int main() {
    // Declare and initialize a string
    std::string greeting = "Hello, world!";

    // Output the string
    std::cout << greeting << std::endl;

    return 0;
}
Output:

Hello, world!

NOTE: Data types is essential for good programming because it determines the type, size, and behaviour of variables and enables proper data manipulation.
