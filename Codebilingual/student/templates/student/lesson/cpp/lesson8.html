  1. if Statement: Executes a block of code if a specified condition is true.
  2. else if Statement: Executes a block of code if the preceding if condition is false and the current condition is true.
  3. else Statement: Executes a block of code if none of the preceding conditions are true.
{% endblock %} {% block content %} 
#include <iostream>
int main() {
    int number = 10;

    // Else if statement
    if (number > 15) {
        std::cout << "The number is greater than 15" << std::endl;
    } else if (number > 5) {
        std::cout << "The number is greater than 5 but less than or equal to 15" << std::endl;
    } else {
        std::cout << "The number is less than or equal to 5" << std::endl;
    }

    return 0;
}

In this example, we have an int variable number initialized with the value 10. We use an if statement to check three conditions sequentially:

  1. The first if statement checks if number is greater than 15. Since number is not greater than 15, this condition is false, and the associated code block is not executed.
  2. The else if statement checks if number is greater than 5. Since number> is indeed greater than 5, but not greater than 15, this condition is true. Therefore, the code block associated with this else if statement is executed, printing "The number is greater than 5 but less than or equal to 15" to the console.
  3. Since the conditions in the preceding if and else if statements are false, the else statement's code block is not executed.

This demonstrates how else if statements provide an alternative condition to check if the preceding condition is false, allowing for multiple conditions to be evaluated in sequence.

  1. Equal to (==)

    #include <iostream>

int main() {
    int a = 5, b = 3;

    // Equal to (==)
    if (a == b) {
        std::cout << "a is equal to b" << std::endl;
    } else {
        std::cout << "a is not equal to b" << std::endl;
    }

    return 0;
}
    Output: 

a is not equal to b

    Since the assigned value to a (5) is not equal to the assigned value to b (3), the condition a == b evaluates to false.

  2. Not equal to (!=)

    #include <iostream>

int main() {
    int a = 5, b = 3;

    // Not equal to (!=)
    if (a != b) {
        std::cout << "a is not equal to b" << std::endl;
    } else {
        std::cout << "a is equal to b" << std::endl;
    }

    return 0;
}
    Output: 

a is not equal to b

    Since the assigned value to a (5) is not equal to the assigned value to b (3), the condition a != b evaluates to true.

  3. Less than (<)

    #include <iostream>

int main() {
    int a = 5, b = 3;

    // Less than (<)
    if (a < b) {
        std::cout << "a is less than b" << std::endl;
    } else {
        std::cout << "a is not less than b" << std::endl;
    }

    return 0;
}
    Output:

a is not less than b

    Since the assigned value to a (5) is not less than the assigned value to b (3), the condition a < b evaluates to false.

    Since the assigned value to a (5) is not less than or equal to the assigned value to b (3), the condition a <= b evaluates to false.
