for loop

A for loop is a control flow statement in C++ that allows you to execute a block of code repeatedly for a fixed number of times. It's especially useful when the number of iterations is known beforehand.

The syntax of a for loop in C++ is as follows:

for (initialization; condition; increment/decrement) {
// code to be executed
}

Here's an explanation of each part of the for loop:

  1. Initialization

    This part is executed only once before the loop starts. It is typically used to initialize a loop control variable.

  2. Condition

    The loop continues to execute as long as this condition remains true. If the condition evaluates to false, the loop terminates.

  3. Increment/Decrement

    This part is executed after each iteration of the loop body. It is used to update the loop control variable. Commonly, it's used for incrementing or decrementing the loop variable.

  4. Loop Body

    This is the block of code that gets executed repeatedly as long as the condition remains true.

Example: 

#include <iostream>

int main() {
for (int i = 0; i < 5; ++i) {
  std::cout << "Iteration " << i + 1 << std::endl;
}

return 0;
}

Let's break it down:

  1. int i = 0; initializes the loop control variable i to 0
  2. int < 5; is the condition. The loop will continue as long as i is less than 5.
  3. i++ is the increment operation. After each iteration, i is incremented by 1.
  4. std::count << "Iteration " << i + 1 << std:: endl; is the loop body. It prints the current iteration number to the console. 
Output:

Iteration 1
Iteration 2
Iteration 3
Iteration 4
Iteration 5

The loop runs five times, printing the current iteration number each time, from 1 to 5.
