C++ Booleans

#include <iostream>
int main() {
    bool isRaining = true;
    bool isSunny = false;

    // Check if it's raining
    if (isRaining) {
        std::cout << "Bring an umbrella!" << std::endl;
    } else {
        std::cout << "No need for an umbrella." << std::endl;
    }

    // Check if it's sunny
    if (isSunny) {
        std::cout << "Enjoy the sunshine!" << std::endl;
    } else {
        std::cout << "It's not sunny right now." << std::endl;
    }

    return 0;
}
  • Two boolean variables isRaining and isSunny are declared and initialized with the values true and false respectively.
  • The program then uses these boolean values in conditional statements to make decisions.
  • In the first if statement, it checks if it's raining (isRaining). If it is, it advises to bring an umbrella; otherwise, it indicates no need for an umbrella.
  • In the second if statement, it checks if it's sunny (isSunny). If it is, it suggests enjoying the sunshine; otherwise, it states that it's not sunny right now. 
Output: 

Bring an umbrella!
It's not sunny right now.
  • For the first condition (isRaining), since isRaining is true, the program prints "Bring an umbrella!".
  • For the second condition (isSunny), since isSunny is false, the program prints "It's not sunny right now.".

The output reflects the logical evaluation of the Boolean variables isRaining and isSunny according to the conditions specified in the code.
