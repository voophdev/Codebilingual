C++ Math

#include <iostream>
#include <math>

int main() {
    double x = 2.5;
    
    // Square root function (sqrt)
    double squareRootResult = std::sqrt(x);
    std::cout << "Square root of " << x << " is: " << squareRootResult << std::endl;

    // Trigonometric sine function (sin)
    double sineResult = std::sin(x);
    std::cout << "Sine of " << x << " is: " << sineResult << std::endl;

    // Exponential function (exp)
    double expResult = std::exp(x);
    std::cout << "Exponential of " << x << " is: " << expResult << std::endl;
    return 0;
}
  • std::sqrt(x): This function calculates the square root of x.
  • std::sin(x): This function calculates the sine of x (where x is in radians).
  • std::exp(x): This function calculates the exponential function, i.e., e raised to the power of x.

These are just a few examples of the many mathematical functions available in C++ through the <cmath> header. 

Output: 

Square root of 2.5 is: 1.58114
Sine of 2.5 is: 0.598472
Exponential of 2.5 is: 12.1825

Here’s a table listing some common math functions provided by the <cmath>:

Function Description
sqrt(x) Returns the square root of x.
sin(x) Returns the sine of x (where x is in radians).
cos(x) Returns the cosine of x (where x is in radians).
tan(x) Returns the tangent of x (where x is in radians).
asin(x) Returns the arc sine (inverse sine) of x in radians, within the range of [-π/2, π/2].
acos(x) Returns the arc cosine (inverse cosine) of x in radians, within the range of [0, π].
atan(x) Returns the arc tangent (inverse tangent) of x in radians, within the range of [-π/2, π/2].
exp(x) Returns the value of e raised to the power of x, where e is the base of the natural logarithm.
log(x) Returns the natural logarithm of x (base e).
log10(x) Returns the base-10 logarithm of x.
pow(x, y) Returns x raised to the power of y.
abs(x) Returns the absolute value of x.
floor(x) Returns the largest integer less than or equal to x.
ceil(x) Returns the smallest integer greater than or equal to x.
round(x) Rounds x to the nearest integer.

These functions are part of the C++ standard library and are commonly used in mathematical calculations.
