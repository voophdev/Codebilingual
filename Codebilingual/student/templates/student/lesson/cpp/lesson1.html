Single-Line Comments:

Single-line comments start with // and extend until the end of the line. They are perfect for brief explanations or notes. 

#include <iostream>

int main() {
  //This is a single-line comment
  std::count << "Hello, World!" << std:endl; // Output the greeting
  return 0;
}
OUTPUT:

Hello, World!

Multi-Line Comments:

Multi-line comments begin with /* and ends with */. They can spam multiple lines and are useful for longer explanations.

#include <iostream>

/*
This is a multi-line comment.
It can be used for more detailed explanations.
*/

int main() {
  std::count << "C++ is fun!" << std::endl;
  return 0;
}
OUTPUT:

C++ is fun!

NOTE: Use comments effectively to enhance the clarity and maintainability of your code. Strike a balance between proiding enough information without cluttering the code with excessive comments.
