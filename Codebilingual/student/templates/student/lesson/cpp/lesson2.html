Declaring Variables:

#include <iostream>

int main() {
  // Declare integer variables
  int age;
  int height = 180; // Declare and initialize a variable

  // Declare floating-point variables
  float pi = 3.14;
  double salary;

  // Output values
  std::cout << "Age: " << age << std::endl; // Output uninitialized variable (undefined behavior)
  std::cout << "Height: " << height << " cm" << std::endl;
  std::cout << "Pi: " << pi << std::endl;
  std::cout << "Salary: " << salary << std::endl; // Output uninitialized variable (undefined behavior)

  return 0;
}

This code in C++ declares variables for age, height, pi, and salary. Variables are like labeled boxes where data can be stored. Here's a quick rundown:

  • int age; - Declares an integer variable for age.
  • int height = 180; - Declares and sets height to 180.
  • float pi = 3.14; - Declares pi as a floating-point number with value 3.14.
  • double salary; - Declares a variable for salary, but it's not given a value yet.
Output:

Age: <undefined>
Height: 180 cm
Pi: 3.14
Salary: <undefined>

NOTE: The values for age and salary are undefined because they have not been assigned any specific value. Accessing uninitialized variables leads to undefined behavior in C++.

Initializing Variables:

#include <iostream>

int main() {
    // Initialize variables at declaration
    int x = 5;
    float y = 3.5;

    // Modify variable value
    x = 10;

    // Output values
    std::cout << "x: " << x << std::endl;
    std::cout << "y: " << y << std::endl;

    return 0;
}

This C++ code demonstrates variable initialization, where variables are assigned initial values when declared. Here's a quick overview:

  • int x = 5; - Declares and initializes an integer variable x with the value 5.
  • float y = 3.5; - Declares and initializes a floating-point variable y with the value 3.5.
  • After initialization, variables can be modified by assigning them new values.
  • Outputting the values of x and y confirms their current values.
Output:

x: 10
y: 3.5

NOTE: Before using a variable in C++, you must declare it, specifying its data type and optionally, its initial value.

  • x is initialized with the value 5, then modified to 10.
  • y is initialized with the value 3.5.
