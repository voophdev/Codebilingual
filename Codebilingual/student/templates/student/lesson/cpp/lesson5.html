Creating a String

#include <iostream>
#include <string>

int main() {
  // Using string literals
  std::string greeting = "Hello, World!";
  
  // Using string constructor
  std::string name("Alice");
  
  // Initializing an empty string
  std::string emptyString;
  
  std::cout << greeting << std::endl;
  std::cout << "My name is " << name << std::endl;
  std::cout << "Empty string: " << emptyString << std::endl;
  
  return 0;
}
Output:

Hello, World!
My name is Alice
Empty string:

As seen in the code provided, there are different methods of creating strings:

  1. Using String Literals

    The greeting variable is initialized with the string literal "Hello, World!". String literals are sequences of sentences enclosed in double quotes. In this case, "Hello, World"is assigned to the greeting variable.

  2. Using String Constructor

    The name variable is created using the constructor of std::string. The constructor is invoked with the argument "Alice", initializing the namevariable with the string "Alice".

  3. Initializing an Empty String

    The emptyString variable is declared without initialization. Since no value is assigned to it, it is an empty string by default.

String Concatenation

The process of combining two or more strings together to form a single string.

#include <iostream>
#include <string>

int main() {
    std::string first = "Hello";
    std::string second = " World!";
    
    std::string combined = first + second;
    
    std::cout << "Combined string: " << combined << std::endl;
    
    return 0;
}
Output:

Combined string: Hello World!

As seen in the code provided, there are different methods of creating strings:

  1. String Variables

    Two std::string variablessfirst and second are declared and initialized with the strings "Hello" and "World!".

  2. Concatenation

    The + operator is used to concatenate the strings first and second, and the result is stored in the combined variable.

Accessing a String

Accessing a string means retrieving or modifying individual characters or substrings within the string. This allows for manipulation and analysis of the text stored in the string object.

#include <iostream>
#include <string>

int main() {
    std::string greeting = "Hello, World!";

    // Accessing individual characters
    char firstChar = greeting[0]; // Accessing the first character
    char fifthChar = greeting[4]; // Accessing the fifth character

    std::cout << "First character: " << firstChar << std::endl;
    std::cout << "Fifth character: " << fifthChar << std::endl;

    // Modifying a character
    greeting[7] = 'w'; // Changing 'W' to 'w'

    std::cout << "Modified string: " << greeting << std::endl;

    return 0;
}

The provided C++ code demonstrates accessing and modifying individual characters within a string:

  1. Accessing Individual Characters

    • Characters in a string can be accessed using square brackets [ ] with the index of the character you want to access.
    • For example, greeting[0] retrieves the first character of the string greeting, and greeting[4] retrieves the fifth character.

  2. Modifying a character

    • Similarly, characters within a string can be modified by assigning a new value to the indexed location.
    • In the code, greeting[7] (which originally contains 'W') is modified to 'w' by assigning 'w' to it. 
Output: 
First character: H
Fifth character: o
Modified string: Hello, world!
  • The program outputs the first and fifth characters retrieved from the string greeting.
  • It also prints the modified string after changing the seventh character to 'w'.

In summary, the code showcases how to access and modify individual characters within a C++ string, offering insight into the fundamental operations for string manipulation.

Escape Characters

In C and C++, escape characters are special sequences of characters used to represent certain non-printable or special characters within strings or character literals. These sequences start with a backslash \ followed by a specific character or sequence of characters.

#include <iostream>

int main() {
  
    std::cout << "Hello, World!\n";
    std::cout << "This is a new line.\n";
    std::cout << "This \t is \t a \t tab \t separated \t line.\n";
    std::cout << "Backspace\b character removes the previous character.\n";
    std::cout << "Carriage return \r moves the cursor to the beginning of the line.\n";
    
    return 0;
}
Output:

Hello, World!
This is a new line.
This     is       a        tab      separated        line.
Backspace character removes the previous character.
Carriage return  moves the cursor to the beginning of the line.

Escape Sequence Table


Escape Sequence Description
'\n' Inserts a newline
'\t' Inserts a tab
'\b' Backspace character, removes the previous character
'\r' Carriage return character, moves the cursor to the beginning of the line

NOTE: Escape characters in C++ serve the vital purpose of representing non-printable or special characters within strings and character literals.These escape sequences significantly enhance the flexibility and precision of string manipulation in C++ programming.
