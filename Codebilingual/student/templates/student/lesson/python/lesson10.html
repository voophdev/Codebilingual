while loop

In Python, a while loop is a control flow statement that repeatedly executes a block of code as long as a specified condition is true. It continues iterating until the condition becomes false. While loops are useful when you want to execute a block of code repeatedly based on some condition.

The syntax of a while loop in Python is as follows: 

while condition
# Code block to be executed repeatedly

Here's an explanation of each part of the while loop:

  1. while: The keyword while initiates the loop.
  2. condition: This is the expression that is evaluated before each iteration of the loop. If the condition evaluates to true, the loop body is executed. If it evaluates to false, the loop terminates, and program execution continues after the loop.
  3. Code block: This is the block of code that is executed repeatedly as long as the condition remains true. It is indented to indicate that it belongs to the while loop.

Here's a simple example of a while loop in Python: 

# Initialize a counter
counter = 0

# While loop with a condition
while counter < 5:
print("Counter:", counter)
counter += 1

Let's break it down:

  1. Initialize a counter: This line initializes a counter variable with a value of 0.
  2. Start of the while loop: This section indicates the beginning of the while loop block.
  3. Condition: The while keyword is followed by a condition that is checked before each iteration of the loop. If the condition evaluates to true, the loop body is executed. If it evaluates to false, the loop terminates.
  4. Loop Body: This is the block of code inside the while loop that gets executed repeatedly as long as the condition remains true. In this example, it prints the current value of the counter and then increments it by 1.
  5. Increment the counter: The counter variable is incremented by 1 after each iteration of the loop.
  6. End of the while loop: This section indicates the end of the while loop block. 
Output:

Counter: 0
Counter: 1
Counter: 2
Counter: 3
Counter: 4

Loop with User Input

An example of while loop that asks the user to enter a number and then prints its multiplication table. 

# Ask user to enter a number, then print its multiplication table using a while loop

num = int(input("Enter a number: "))
i = 1
while i <= 10:
print(num, "x", i, "=", num * i)
i += 1

Output:

Enter a number: 5 (the number 5 is inputted by the user)
5 x 1 = 5
5 x 2 = 10
5 x 3 = 15
5 x 4 = 20
5 x 5 = 25
5 x 6 = 30
5 x 7 = 35
5 x 8 = 40
5 x 9 = 45
5 x 10 = 50

Infinite Loop with Break Statement

Like all loops, infinite loops can be exited prematurely using the break and exit statements. 

# Count from 1 to 10 but break the loop when the number becomes 5

num = 1
while True:
print(num)
if num == 5:
  break
num += 1
Output:

1
2
3
4
5

While Loop with Else Block

A while loop example that checks if a number is prime and uses an else block to handle the case when the loop completes without encountering a break statement. 

# Check if a number is prime using a while loop with an else block

num = int(input("Enter a number: "))
i = 2
while i < num:
if num % i == 0:
  print(num, "is not a prime number.")
  break
i += 1
else:
print(num, "is a prime number.")
Output:

Enter a number: 7 (the number 7 is inputted by the user) 
7 is a prime number.

Explanation:

This code checks if a given number (num) is prime or not. It iterates through numbers from 2 to num – 1 (excluding num itself) and checks if num is divisible by any of these numbers. If it finds a divisor, it prints that num is not a prime number and breaks out of the loop. If no divisors are found, it prints that num is a prime number.

NOTE: While loops offer a flexible way to repeat a block of code in Python until a certain condition is met, making them essential for tasks like iterative processing, user input validation, and creating infinite loops with break conditions.
