Boolean Variables

#Boolean variable assignment
is_sunny = True
is_raining = False

print(is_sunny)     # Output: True
print(is_raining)   # Output: False

Boolean Operations

Boolean operations allow combining boolean values using logical AND, OR, and NOT. 

#Boolean operations

sunny = True
raining = False

# Logical AND operation
is_good_weather = sunny and not raining
print(is_good_weather)   # Output: True

# Logical OR operation
is_any_weather = sunny or raining
print(is_any_weather)    # Output: True

Here's the breakdown of the code:

  • is_good_weather checks if it's sunny and not raining. Since it's sunny (sunny is True) and not raining (not raining is also True), the result is True.

  • is_any_weather checks if it's either sunny or raining. Since it's sunny (sunny is True), the result is True because at least one of them (sunny) is True.

  • So both outputs are True, indicating that it's good weather and there's some kind of weather (either sunny or raining).
