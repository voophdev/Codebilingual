In Python, a variable is a name that refers to a value stored in memory. Unlike some other programming languages, Python is dynamically typed, meaning you don't have to explicitly declare the type of a variable before assigning a value to it. Variables in Python can hold various types of data, such as numbers, strings, lists, or even more complex objects.

Assigning Values to Variables

#Assigning integer value to a variable
age = 22

# Assigning string value to a variable
name = "Angel"

# Assigning float value to a variable
height = 5.8

# Assigning boolean value to a variable
is_student = True

print(age)
print(name)
print(height)
print(is_student)

This Python code demonstrates the concept of variable assignment. Here's what each part of the code does:

  • age = 22: This line assigns an integer value 22 to the variable age. It declares a variable named age and assigns it the value 22.

  • name = "Angel": This line assigns a string value "Angel" to the variable name. It declares a variable named name and assigns it the value "Angel".

  • height = 5.8: This line assigns a float value 5.8 to the variable named height. It declares a variable named height and assigns it the value 5.8. 

Output:

22
Angel
5.8
True

NOTE: In Python, you don't need to explicitly declare data types for variables because Python automatically determines the data type based on the value assigned to the variable.

Variable Reassignment

Variable reassignment in Python refers to the process of assigning a new value to a variable that already exists, potentially changing its type or content. 


x = 5
print("Initial value:", x)  # Output: 5

x = x + 2
print("Reassigned value:", x) #Output: 7

In this example, the value of x is initially set to 5, then it's reassigned to x + 2, resulting in 7. 

Output:

Initial value: 5
Reassigned value: 7

Multiple Assignment

Python multiple assignment variable is a feature that allows assigning multiple values to multiple variables in a single line of code. This provides a convenient and concise way to assign values to multiple variables simultaneously, which can improve readability and reduce the amount of code needed for assignments. 

a, b, c = 10, 20, 30

print(a)   # Output: 10
print(b)   # Output: 20
print(c)   # Output: 30

This Python code simultaneously assigns the values 10, 20, and 30 to variables a, b, and c, respectively. Then it prints each variable's value 

Output:

10
20
30

Using Variables in Expressions

Before discussing Python variable usage, let's define Python expressions. These are combinations of variables, values, operators, and functions that produce results, ranging from simple to complex operations. Examples include arithmetic expressions like 5 + 3, boolean expressions like x > 10

To use variables in Python expressions, simply include them alongside values, operators, and functions within the expression. Variables hold data that can be manipulated or combined with other values and operations to produce results within the expression. 

# Define variables
x = 5
y = 3

# Use variables in an expression
result = x + y
print(result)  # Output: 8

In this example, x and y are variables holding the values 5 and 3, respectively. The expression x + y combines these variables with the addition operator (+) to produce the result 8, which is then stored in the variable result and printed. 

Output:

8

NOTE:

  • Variable names can contain letters (a-z, A-Z), digits (0-9), and underscores (_).
  • Variable names must begin with a letter or an underscore.
  • Variable names are case-sensitive.
  • Variable names cannot be Python keywords or reserved words.
