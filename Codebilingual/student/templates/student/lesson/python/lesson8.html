If Statement

The if statement is used to execute a block of code if a specified condition is true. 

x = 10

if x > 5:
print("x is greater than 5")

#output: x is greater than 5

Here's the breakdown of the code:

  • The variable x is assigned the value 10.
  • The if statement checks if the value of x is greater than 5.
  • Since x is indeed greater than 5 (10 > 5), the condition evaluates to True.
  • As a result, the print() statement inside the if block is executed.
  • Therefore, the output will be: x is greater than 5.

Elif Statement

The elif statement allows you to check multiple conditions. 

x = 10

if x < 0:
print("x is negative")
elif x == 0:
print("x is zero")
else:
print("x is positive")

#output: x is positive

Here's the breakdown of the code:

  • If x is less than 0 (x < 0), it prints "x is negative".
  • If x is equal to 0 (x == 0), it prints "x is zero".
  • If neither of the above conditions is true (i.e., x is greater than 0), it prints "x is positive".

Elif Statement

It executes a block of code if none of the preceding conditions are true. 

x = -5
if x > 0:
print("x is positive")
elif x == 0:
print("x is zero")
else:
print("x is negative")

#output: x is negative

In this example:

  • The variable x is assigned the value -5.
  • The first if condition checks if x is greater than 0, which is not true in this case.
  • The next elif condition checks if x is equal to 0, which is also not true.
  • Since neither the if nor the elif conditions are true, the else block is executed.
  • Therefore, the output will be: x is negative.
