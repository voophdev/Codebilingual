Single-Line Comments:

Single-line comments start with the # symbol and continue until the end of the line. They are often used for brief explanations or annotations. 

#This is a single-line comment

print("Hello, World!")  #This comment follows a statement
OUTPUT:

Hello, World!

Multi-Line Comments:

Multi-line comments are enclosed within triple quotes (""" or '''). While Python doesn't have a specific syntax for multi-line comments, using triple quotes for string literals effectively serves as a way to include multi-line comments. 

"""
This is a multi-line comment.
It spans multiple lines.
This is useful for longer explanations.
"""

print("Hello, World!")
OUTPUT:

Hello, World!

NOTE: Python comments play a crucial role in enhancing code readability, documenting functionality, and facilitating collaboration among developers. They are an essential tool for writing clean and understandable code.
