Array Indexing

In Python, array indexing is used to access individual elements of an array or a list. Python uses zero-based indexing, which means that the index of the first element in the array is 0, the index of the second element is 1, and so on. 

# Define an array or list

my_array = [10, 20, 30, 40, 50]

# Accessing elements using indexing
print(my_array[0])  # Access the first element (index 0)
print(my_array[1])  # Access the second element (index 1)
print(my_array[2])  # Access the third element (index 2)
# and so on...

# Negative indexing: Access elements from the end of the array
print(my_array[-1])  # Access the last element
print(my_array[-2])  # Access the second-to-last element
# and so on...
  • Zero-based indexing: Python uses zero-based indexing, where the index of the first element in the array is 0, the index of the second element is 1, and so on.
  • Accessing elements: Elements of the array can be accessed using square brackets [] with the index of the element inside.
  • Negative indexing: Python also supports negative indexing, where the index of -1 represents the last element, -2 represents the second-to-last element, and so on.
  • IndexError: Trying to access an index beyond the length of the array will result in an IndexError.
Output:

10
20
30
50

Creating a Simple Array

You can create arrays using lists. Lists are a built-in data type that can store multiple values separated by commas and enclosed within square brackets. 

# Syntax: variable_name = [value1, value2, value3, ...]
fruits = ["apple", "banana", "orange", "grape", "kiwi"]

# Accessing elements of the array
print("First fruit:", fruits[0])  # Output: apple
print("Second fruit:", fruits[1])  # Output: banana
print("Last fruit:", fruits[-1])   # Output: kiwi
Output:

First fruit: apple
Second fruit: banana
Last fruit: kiwi

Let's break it down:

  • We define an array named fruits containing the names of different fruits.
  • Each fruit name is enclosed in double quotes and separated by commas.
  • To access elements of the array, we use square brackets [] along with the index of the element we want to access.
  • Remember that in Python, indexing starts from 0, so fruits[0] refers to the first element, fruits[1] refers to the second element, and so on. Additionally, negative indexing -1 refers to the last element of the array, -2 refers to the second last element, and so forth.

Adding Elements to a Array

import array as arr

a = arr.array('i', [1, 2, 3])
print("Array before insertion : ", end=" ")

for i in range(0, 3):
print(a[i], end=" ")
print()

a.insert(1, 4)
print("Array after insertion : ", end=" ")

for i in (a):
print(i, end=" ")
print()

b = arr.array('d', [2.5, 3.2, 3.3])
print("Array before insertion : ", end=" ")

for i in range(0, 3):
print(b[i], end=" ")
print()

b.append(4.4)
print("Array after insertion : ", end=" ")

for i in (b):
print(i, end=" ")
print()
Output:

Array before insertion :  1 2 3 
Array after insertion :  1 4 2 3 
Array before insertion :  2.5 3.2 3.3 
Array after insertion :  2.5 3.2 3.3 4.4

Let's break it down:

  • For array a, before insertion, the elements are 1 2 3. After insertion of 4 at index 1, the elements become 1 4 2 3.
  • For array b, before insertion, the elements are 2.5 3.2 3.3. After appending 4.4 to the end, the elements become 2.5 3.2 3.3 4.4.

Removing Elements from the Array

import array

arr = array.array('i', [1, 2, 3, 1, 5])
print("The new created array is : ", end="")

for i in range(0, 5):
print(arr[i], end=" ")

print("\r")
print("The popped element is : ", end="")
print(arr.pop(2))
print("The array after popping is : ", end="")

for i in range(0, 4):
print(arr[i], end=" ")

print("\r")
arr.remove(1)
print("The array after removing is : ", end="")

for i in range(0, 3):
print(arr[i], end=" ")
Output:

The new created array is : 1 2 3 1 5 
The popped element is : 3
The array after popping is : 1 2 1 5 
The array after removing is : 2 1 5

Let's break it down:

  • The initial array is [1, 2, 3, 1, 5].
  • After popping the element at index 2, the array becomes [1, 2, 1, 5], and the popped element is 3.
  • After removing the first occurrence of 1, the array becomes [2, 1, 5].
  • The final output shows the array at different stages of modification.

Searching Elementin an Array

import array

arr = array.array('i', [1, 2, 3, 1, 2, 5])
print("The new created array is : ", end="")
for i in range(0, 6):
print(arr[i], end=" ")

print("\r")
print("The index of 1st occurrence of 2 is : ", end="")
print(arr.index(2))
print("The index of 1st occurrence of 1 is : ", end="")
print(arr.index(1))
Output:

The new created array is : 1 2 3 1 2 5 
The index of 1st occurrence of 2 is : 1
The index of 1st occurrence of 1 is : 0

Let's break it down:

  • The initial array is [1, 2, 3, 1, 2, 5].
  • The index of the first occurrence of 2 in the array is 1.
  • The index of the first occurrence of 1 in the array is 0.
  • The final output shows the array and the indices of the first occurrences of 2 and 1.

Updating Elements in an Array

import array

arr = array.array('i', [1, 2, 3, 1, 2, 5])
print("Array before the update : ", end="")
for i in range(0, 6):
print(arr[i], end=" ")

print("\r")
arr[2] = 6
print("Array after the update : ", end="")
for i in range(0, 6):
print(arr[i], end=" ")
print()

arr[4] = 8
print("Array after the update : ", end="")

for i in range(0, 6):
print(arr[i], end=" ")
Output:

Array before the update : 1 2 3 1 2 5 
Array after the update : 1 2 6 1 2 5 
Array after the update : 1 2 6 1 8 5

Let's break it down:

  • Initially, the array is [1, 2, 3, 1, 2, 5].
  • After the first update, the array becomes [1, 2, 6, 1, 2, 5] because the element at index 2 is updated from 3 to 6.
  • After the second update, the array becomes [1, 2, 6, 1, 8, 5] because the element at index 4 is updated from 2 to 8.

NOTE: Arrays are versatile data structures that allow you to store and manipulate collections of values efficiently. Arrays play a crucial role in many programming tasks, providing a convenient way to organize and access data elements.
