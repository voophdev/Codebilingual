Looping in Python refers to the process of repeatedly executing a block of code multiple times. They enable efficient and organized handling of tasks that need to be performed repeatedly. Loops help streamline code by reducing redundancy and improving readability.

for loop

In Python, a for loop is used to iterate over a sequence (such as a list, tuple, string, or range) or any iterable object. It executes a block of code repeatedly for each item in the sequence, allowing you to perform operations on each element without the need for manual indexing.

The syntax of a for loop in Python is as follows: 

for item in sequence:
# do something with item
}

Example:

fruits = ["apple", "banana", "cherry", "date"]

for fruit in fruits:
print(fruit)

Here's an explanation of each part of the for loop:

  1. Iterable: In this example, fruits is the iterable, which is a list containing different types of fruits.
  2. Loop Variable (fruit): fruit is the loop variable. During each iteration of the loop, it takes on the value of the current item in the fruits list.
  3. Loop Body: The loop body consists of the print(fruit) statement. This statement is executed for each item in the fruits list. During each iteration, it prints the value of the current fruit.

The for loop iterates over each item in the fruits list, assigns the value of each item to the loop variable fruit, and executes the loop body for each item. This results in printing each fruit name on a separate line.

Iterating Over a list

Iterates over each item in a list and performs an action for each item.

# Iterating over a list of numbers

numbers = [1, 2, 3, 4, 5]
for num in numbers:
print(num)
Output:

1
2
3
4
5

Iterating Over a String

Iterates over each character in a string and performs an action for each character.

# Iterating over a string
message = "Hello"
for char in message:
print(char)
Output:

H
e
l
l
o

Using Range with For Loop

Iterates over a sequence of numbers using the range() function.

# Using range to iterate over a sequence of numbers
for i in range(5):
print(i)
Output:

0
1
2
3
4

Iterating Over Dictionary Items

Iterates over key-value pairs in a dictionary and performs an action for each pair.

# Iterating over dictionary keys and values

student_grades = {"Alice": 85, "Bob": 90, "Charlie": 75}
for name, grade in student_grades.items():
print(f"{name}: {grade}")
Output:

Alice: 85
Bob: 90
Charlie: 75

Using Else with For Loop

Checks for the presence of an element in a list and executes an action accordingly.

# Checking for the presence of an element in a list

fruits = ["apple", "banana", "orange"]
for fruit in fruits:
if fruit == "banana":
  print("Banana found!")
  break
else:
print("Banana not found!")
Output:

Banana found!

Explanation:

This Python code defines a list of fruits. It iterates through each fruit in the list and checks if it's equal to banana. If a banana is found, it prints Banana found! and exits the loop using the break statement. If no banana is found after iterating through all fruits, it prints Banana not found!. In this specific case, since banana is in the list, it prints Banana found!. The else block is associated with the for loop and is executed if the loop completes without encountering a break.

NOTE: Python for loops provide a simple and concise way to iterate over elements in a sequence or any iterable object, making them versatile for various programming tasks.
